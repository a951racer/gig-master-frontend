# Background Images

Place your background PNG images in this directory.

## Required Files

### `login-bg.png`
- Used on the login page only
- A dark semi-transparent overlay is applied over this image
- Recommended: 1920x1080 or higher, dark-themed

### `app-bg.png`
- Used as the background for all other pages (songs, playlists, gigs, admin, etc.)
- Fixed position so it stays in place while content scrolls
- Recommended: 1920x1080 or higher, dark-themed to complement the purple UI
